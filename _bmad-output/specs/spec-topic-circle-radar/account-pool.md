# 重点主题圈账号池

每个账号配置X handle、所属主题圈、启停状态、账号角色和适用的权威范围。账号角色分为官方账号、核心人物账号和其他监控账号；权威范围用于限定官方账号或核心人物的直接Hot Event触发权限。

账号体量、账号角色、权威范围和可信度均不参与三个榜单排序。三个榜单只使用浏览量和浏览量快照；账号角色与权威范围只用于Hot Event准入和Evidence来源标记。
