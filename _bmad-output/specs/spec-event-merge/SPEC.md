# 跨来源事件合并 SPEC

## Why

热搜榜、未来事件和主题圈可以独立发现同一现实事件。如果每次来源触发都建立独立 Event 和下游任务，运营人员会收到重复候选并可能重复发布。本能力让三个来源保持独立触发，同时在事件管理层统一识别同一事件、合并来源上下文并控制重复响应。

## Capabilities

- **CAP-1 独立来源接入**
  - **intent:** 系统可以接收热搜榜、未来事件和主题圈独立触发产生的来源子 Event Context Pack。
  - **success:** 任一来源达到自身门槛后可以独立进入事件管理，且来源、触发时间、触发依据、规则版本、事实边界和 Evidence 均被保留。

- **CAP-2 同一事件匹配**
  - **intent:** 事件管理可以判断来源子 Event 与已有主 Event 是否描述同一现实事件。
  - **success:** 每次判断均基于主体、核心动作、对象、时间、地点、事件状态和事实含义，输出各维度分数、依据与冲突点。

- **CAP-3 合并决策**
  - **intent:** 系统可以自动合并高置信匹配，并把不确定匹配交给运营人员复核。
  - **success:** 通过硬门槛且置信度不低于 `0.95` 时自动合并；`0.80–0.9499` 进入人工复核；低于 `0.80` 保持独立；命中硬冲突时禁止自动合并。

- **CAP-4 统一来源上下文**
  - **intent:** 主 Event 可以汇集多个来源上下文而不破坏各来源的原始记录和事实边界。
  - **success:** `trend_context`、`schedule_context` 与 `topic_circle_context` 可以并存，原始子包可追溯且不互相覆盖，来源增加不会自动提高事实确认等级。

- **CAP-5 重复响应控制**
  - **intent:** 系统可以避免同一现实事件因多个来源先后触发而重复启动默认响应。
  - **success:** 响应任务以主 Event、账号和 Skill 版本保持唯一；后到同类来源只更新上下文，首次新增来源类型只产生一次运营提醒，不自动重复生成或发布。

- **CAP-6 在途与已发布保护**
  - **intent:** 系统可以根据主 Event 当前响应状态安全处理后到来源。
  - **success:** 未发布候选按事实与表达边界变化继续、重新预检或冻结；已发布内容及其 Event Context Pack 版本保持不可变，冲突信息产生复核提醒。

- **CAP-7 事件演化区分**
  - **intent:** 系统可以把同一事实的来源补充与新的事实发展区分开。
  - **success:** 新动作、正式落地、结果、改期、取消、更正或反转形成独立关联 Event，并拥有独立事实、触发状态和响应任务。

- **CAP-8 未合并事件路由**
  - **intent:** 达到来源触发门槛但未达到自动合并门槛的子 Event 可以作为独立 Event 正常响应。
  - **success:** `0.80–0.9499` 的匹配在进入人工复核的同时独立向下游路由；低于 `0.80` 或命中硬冲突的事件保持独立并正常路由，不因合并判断或人工复核而阻塞。

## Constraints

- 三个来源分别按照自身规则触发；来源层不查询、不等待其他来源，也不执行跨来源合并。
- 来源门槛决定响应资格，事件匹配只决定是否去重；合并不得成为新的响应门禁。
- 事件管理不得再定义“明显热度跃迁”；来源达到自身门槛即构成该来源的一次有效触发。
- 标题、关键词、语言、榜单地区、热度或相同人物不能单独作为合并依据。
- Signal、热搜排名、代表帖子和主题圈讨论不得因合并被升级为现实事实证据。
- 合并不得重写历史 Event、Evidence、内容、发布记录或其版本引用。
- 自动合并、人工决定、上下文变化、任务影响和关联关系必须完整审计。

## Non-goals

- 不定义热搜榜、未来事件或主题圈各自的触发算法与门槛。
- 不根据多个来源共同命中重新计算 Action Score、Confirmation Level 或事实可信度。
- 不自动决定首次新增来源后是否值得制作跟进内容；系统只提醒运营人员。
- 不自动修改、删除或重新发布已经发布的内容。
- 不因进入人工合并队列而暂停一个已经取得独立响应资格的 Event。

## Success signal

同一现实事件先后由三个来源触发时，事件管理最终只保留一个主 Event 和一组默认账号响应任务，同时完整展示三个来源上下文；新的事实发展则建立可追溯的关联 Event，不被错误吞并。
