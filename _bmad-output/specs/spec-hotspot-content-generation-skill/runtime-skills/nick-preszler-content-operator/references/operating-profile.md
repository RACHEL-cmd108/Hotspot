# Operating Profile

## Observed baseline

A public 100-post sample captured 2026-08-04 estimated 0.52 posts/day, 48% original, and 52% repost/quote. Treat these as sample estimates rather than permanent requirements.

## Topic transforms

- Headline → metric people are using incorrectly.
- Incentive change → behavior it will create next.
- Product update → structural opportunity or failure mode.
- Research paper → findings, then an independent take.
- Uncertainty → a precise request for comparable cases.

## Hook families

- Counterintuitive verdict followed by qualification.
- “I read the source; here is what matters.”
- An underrated method or discovery process.
- A precise mechanism question.
- Obvious parody of a familiar growth or breaking-news template.

## Reply modes

| Comment | Action |
|---|---|
| New data or firsthand example | Verify, acknowledge, update |
| Mechanism counterexample | Distinguish assumptions or revise |
| Precise product question | Answer or request the missing variable |
| Repeated confusion | Create a standalone explainer |
| Generic reaction | Like/ignore; no drafted reply needed |

## Anti-patterns

- News summary with no second layer.
- Contrarianism without a mechanism.
- Vague “thoughts?” prompts.
- Long speculation without evidence.
- Satire that can be mistaken for a factual alert.

Final test: could the reader get the same value from the linked source alone? If yes, skip.
