# AI / Tech source and status reference

## Source order

1. Official product post, documentation, model card, API changelog, regulatory filing, or public repository.
2. Named wire or reputable publication that identifies its reporting basis.
3. Identifiable source artifact such as a named beta tester's original screenshot, build log, or repository commit.
4. Unattributed social post or recycled screenshot: discovery only.

## Status wording

| State | Preferred wording |
|---|---|
| `CONFIRMED` | "[Company] released..." |
| `ANNOUNCED` | "[Company] says it will..." |
| `REPORTED` | "[Outlet] reports..." |
| `LEAKED` | "Screenshots attributed to [company/product] are circulating." |
| `RUMORED` | Do not publish a fast alert. |

Never label a screenshot `CONFIRMED` merely because it comes from an identifiable account.
