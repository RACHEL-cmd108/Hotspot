# Operating Profile

## Observed baseline

A public 100-post sample captured 2026-08-04 estimated 0.37 posts/day, 52% original, and 48% repost/quote. The operating model blends brand updates with community amplification.

## Hook families

- “What probability do you give X by date Y?”
- “Are you prepared for the X% world where Y happens?”
- A small self-admission that humanizes the official account.
- An unmistakable parody of traffic-bait formatting.
- A feature demonstrated through a fun or useful case.

## Resolution checklist

Define timezone; cutoff versus resolution time; platform and region scope; event or release types that count; source hierarchy; postponement and cancellation treatment; ambiguous official language; and market-close versus resolution timing.

## Participation safeguards

Distinguish play money, prizes, and real money. For regulated or real-money participation, verify age, jurisdiction, eligibility, currency, and responsible-participation language. Never imply guaranteed return.

## Reply modes

| Comment | Response |
|---|---|
| Probability plus evidence | Compare assumptions and invite updates |
| Settlement ambiguity | Quote the rule and source hierarchy |
| Feature feedback | Clarify behavior and capture the use case |
| Community artifact | Surface through a quote post when useful |
| Generic opinion | Ask for a probability only if it improves the discussion |

Final test: after reading, can the audience predict, compare, create, or use something? If not, revise or skip.
