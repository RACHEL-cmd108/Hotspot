# Operating Profile

## Observed baseline

A public 100-post sample captured 2026-08-04 estimated 1.2 posts/day, 16% original, and 84% repost/quote by public classification. Bookmarks represented about 65.3% of measured engagement actions, indicating future-use content.

## Topic transforms

- Expert trend → distilled learning path.
- Course/paper → what the reader can now understand or do.
- Career case → replicable steps plus constraints.
- Tool launch → task saved and workflow changed.
- Technical breakthrough → plain-language consequence and resources.

## Hook families

- A verified person achieving X and how they learned.
- Avoid wasting N years; use this sequence instead.
- No elite credential, but a documented result—plus prerequisites.
- A top organization's process explained by a primary resource.
- The N resources or steps that matter.

## Reply modes

| Comment | Response |
|---|---|
| “Where do I start?” | First prerequisite and first resource |
| Access/link issue | Verify current link, region, price, license |
| Missing prerequisite | Add it visibly; revise the parent if material |
| Alternative resource | Compare audience, level, and goal |
| Unverified success claim | Request evidence; do not amplify |

Final test: would a reader bookmark this because it changes what they can do next?
