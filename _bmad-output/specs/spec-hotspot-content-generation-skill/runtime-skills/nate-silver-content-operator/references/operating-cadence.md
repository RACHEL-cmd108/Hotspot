# Operating cadence

## Default weekly rhythm

| Frequency | Content |
|---|---|
| Daily | Scan events and data; publish 1-3 items only when an analytical edge exists |
| 2-4 times/week | Quote/context posts that correct a comparison or add a condition |
| 1-2 times/week | Native analytical post with chart, cross-tab, or probability update |
| Weekly | `What changed my mind` update ledger |
| Weekly or biweekly | Deep analysis built from a recurring dispute or model question |
| Monthly | Postmortem on prior calls and one adjacent quantitative experiment |

Treat the numbers as ceilings, not quotas. Reduce output when evidence is weak.

## Event window

### Before a scheduled event

- Write the prior probability or baseline.
- List the two or three variables that matter.
- Predefine what outcomes would trigger an update.

### During the event

- Publish only material updates.
- Distinguish signal from noise.
- Avoid multiple posts that repeat the same thesis.

### After the event

- Compare outcome with the prior.
- Explain the update and remaining uncertainty.
- Capture recurring lessons in a durable framework.

## Topic backlog fields

Maintain:

- topic;
- audience relevance;
- current public narrative;
- missing baseline;
- available primary data;
- likely incentive mechanism;
- tentative conclusion;
- confidence;
- falsifier;
- response level;
- status: watch, ready, published, escalated, retired.

## Performance review

Do not optimize only for likes. Review:

- qualified reach among the intended audience;
- replies containing evidence or substantive questions;
- saves/bookmarks and shares;
- citations or adoption of the framework;
- profile or owned-channel conversion when available;
- whether the post created a durable follow-up asset;
- whether later evidence supported the claim.

Separate a high-conflict post from a high-trust post. Large reply volume can mean confusion or hostility rather than useful engagement.

## Cadence guardrails

- Default to no more than 1-2 posts per hour.
- Do not quote-post several reactions to the same claim without adding a new analytical layer.
- Do not force a daily hot take.
- Pause when primary information is unavailable.
- Revisit forecasts on a defined schedule instead of only when favorable evidence appears.
- Maintain an update ledger to prevent selective memory.
