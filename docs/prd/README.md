# 产品需求文档

本部分定义 Predx 热点运营系统的用户场景、功能范围、数据字段、业务规则和验收要求。

## 正式版本

- `releases/Predx热点运营产品需求文档_PRD_v1.2_完整修复版.docx`：当前版本。
- `releases/Predx热点运营产品需求文档_PRD_v1.2_完整修复版.pdf`：当前版本 PDF。
- `releases/` 中的 v1.0 和 v1.1：历史版本。

## 生成方式

在仓库根目录运行：

```bash
python3 build_hotspot_prd.py
```

脚本会更新当前 v1.2 Word 文档及 `assets/` 中的产品架构图。
