# 05 安全与运维

## 身份、权限与数据

| 控制 | 架构要求 |
| --- | --- |
| 登录 | Google Workspace OIDC；允许域与账号状态校验；会话安全 Cookie、短生命周期和登出失效。 |
| 角色 | 监测运营、内容运营、活动运营、审核/风险、配置管理员、系统管理员；页面可见不代表拥有命令权限。 |
| 高风险命令 | 发布配置、批准高风险候选、导出活动方案、权限变更、人工接管必须二次授权并审计；高风险审批人与作者分离。 |
| 密钥 | X、AI、Google、数据库凭据仅在托管密钥服务或运行时注入；不进入代码、业务表、浏览器和普通日志。 |
| 数据 | 仅保存履行产品所需的公开来源快照、链接、运营记录和工作身份；导出按角色与最小字段集控制。 |

## 可观测性与处置

| 信号 | 记录 | 告警条件 |
| --- | --- | --- |
| 采集 | 五地区成功率、每地区来源数、限流/认证/超时 | 连续采集失败、来源数异常下降、凭据失效 |
| 生成 | ART 创建、候选数、预检结果、队列滞留 | 任务重复失败、可用候选少于三条、队列延迟 |
| 人工闭环 | 选择、URL/失败原因回填、各阶段实际耗时 | 长时间待处理、异常未接管 |
| 恢复 | 备份结果、恢复演练、数据库/Worker 健康 | 备份失败、RPO/RTO 风险、关键依赖不可用 |

日志带 request ID、对象 ID 和审计关联，不记录密钥或超出边界的 AI 输入。发生 X/AI 故障时保留权威状态并暂停相应任务；运营人员可查看失败、重试或接管，不得静默跳过。
