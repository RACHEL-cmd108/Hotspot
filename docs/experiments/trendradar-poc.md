# TrendRadar 热点内容通路 POC

## 实验定位

这是项目的第一个可行性验证，目的是确认“从外部热点数据到待审核内容草稿”的关键链路能否跑通，而不是将 TrendRadar 作为最终产品方案。

## 实验链路

```text
TrendRadar 热点数据
→ 读取最新 SQLite 数据库
→ 候选事件标准化
→ 来源可靠性、时效、传播速度和受众适配评分
→ 生成三类 X 内容草稿
→ 字数、禁用表述、异常数字、来源链接和版本相似度检查
→ 输出待人工审核结果
```

## 已验证

- 可以以只读方式获取 TrendRadar 的热点数据。
- 可以将外部热点转换为统一行动任务包。
- 可以根据热度和账号适配度进行承接决策。
- 可以生成 `news_alert`、`information_reframe` 和 `original_commentary` 三类草稿。
- 相关原型的 9 个单元测试已通过。

## 尚未验证

- TrendRadar 是否适合作为生产环境的长期数据源。
- 多信源事件聚类、去重和真实热度的稳定性。
- 内容生成在真实运营场景中的质量与可控性。
- 人工审核工作台、任务调度、监控和发布流程。
