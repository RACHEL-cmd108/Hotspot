# 事件确认等级决定下游表达边界，而非行动分上限

Hotspot Monitor 将 Event 的事实确认等级映射为四种下游表达边界：`factual`、`qualified`、`internal_only` 和 `blocked`。行动分继续只表示当前运营优先级，不再以确认等级强行封顶；这样高热但未完全确认的事件可以被及时监控和准备，同时所有对外内容仍必须保留与证据相符的限定表达，避免把“值得响应”误写成“已被证实”。

Event 向下游提供的是 Event Context Pack：事件说明、当前状态、已确认与未确认事实、证据、时间信息和表达边界。Context Pack 不规定内容数量、渠道、形式或活动方案；下游模块可以按自身请求生成社媒内容、设计文案、活动方案或其他交付物，但必须遵守其中的表达边界。
