开发交互说明

  1. 三个一级路由：选题推荐、上下文收件箱、决策记录。
  2. 选题详情与记录回溯均使用右侧抽屉。
  3. “采用”必须关联具体Angle ID和版本；“不采用”应记录原因。
  4. “重新推荐”保留已选角度并生成新版本，不计作最终结果。
  5. 采用率分母只包含已审核选题，不包含待处理推荐。
  6. 提交上下文后先进入收件箱，完成准入判断后才进入推荐。
