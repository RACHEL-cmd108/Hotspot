## 文件管理规则

- 每个业务模块在本目录只保留一份当前原型。
- 新原型被确认为当前版本后，旧稿移入本地 `../archive/prototype-history/YYYY-MM-DD/`。
- `final`、`v2` 等文件名只表示产生时的版本语义；是否为当前稿以本索引为准。
- archive 只用于本地追溯，不同步远端。
