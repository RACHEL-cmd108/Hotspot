# 06 视觉设计与组件

## 6.1 视觉基线

本版继承 [HTML 原型终稿 v13](./prototype/hotspot-operations-system-final-prototype.html) 的桌面运营工作台语言：暖灰背景、白色信息面板、深青绿作为主要操作和正向状态、橙色表示待处理/限制、红色表示异常或高风险。HTML 用于演示完整产品链路；一期是否接通某个能力，仍以本版 Phase 0 范围为准。颜色不是唯一语义，所有状态同时使用文字和图形/布局区分。

| 元素 | 规范 |
|---|---|
| 页面框架 | 左侧固定一级导航；顶部为工作空间、链路健康、待处理和账户入口；主内容宽画布。 |
| 信息密度 | 榜单、任务和来源采用表格/列表；对象详情采用左右主从布局；候选、活动方案使用并列卡片比较。 |
| 状态标签 | 使用“来源一致/冲突/未知”“待选择”“待回填”“异常”“预留能力”等业务词，不能只显示绿/橙/红。 |
| 预留能力 | 使用“后续模块/未启用”标签和明确边界，不出现可执行 CTA 或模拟生产数据。 |
| 来源链接 | 来源名称、URL、地区、快照时间、来源状态相邻展示；外链有明确打开标识。 |

## 6.2 设计变量与桌面适配

以下变量为开发实现的设计基线；具体组件不得直接散落使用未登记的色值、字号或间距。

| 类别 | Token | 值 / 规则 |
|---|---|---|
| 颜色 | `color.canvas` / `color.surface` / `color.text` | `#F4F7F7` / `#FFFFFF` / `#172026` |
| 颜色 | `color.primary` / `color.primary-hover` | `#087B71` / `#05665E`；仅用于主操作、当前导航和正向强调 |
| 颜色 | `color.warning` / `color.danger` | `#B55020` / `#A53D44`；必须与状态文字、图标或位置共同出现 |
| 颜色 | `color.border` / `color.focus` | `#D6DFDF` / `#82C1BB`；键盘焦点使用 3px 外描边，不用颜色变化代替焦点 |
| 字体 | `font.body` / `text.body` | 系统无衬线字体栈；14px / 1.5 为默认正文 |
| 字体 | `text.meta` / `text.title` / `text.page-title` | 11px / 17px / 25px；元信息不可低于 11px |
| 间距 | `space.1—6` | 4 / 8 / 12 / 16 / 24 / 32px；卡片内边距默认 16px |
| 形状 | `radius.card` / `shadow.overlay` | 0px（表格/面板保持克制）/ `0 16px 46px #163E3B1A` |

| 桌面断点 | 布局规则 |
|---|---|
| ≥ 1440px | 左侧导航 224px；内容最大宽度 1510px；排行榜、任务表与三候选并列展示。 |
| 1180—1439px | 保留左侧导航；指标缩为两至三列；主从双栏可收为上下结构；表格保留横向滚动与固定表头。 |
| < 1180px | 本版不作为正式支持目标；不得通过裁切隐藏关键列。若开放访问，改为单列、可横向滚动表格，并显示“桌面体验建议 ≥1180px”。 |
| 400% 缩放 | 主从布局转为单列；候选与方案从三列转为一列；导航、筛选、表单和对话框仍可键盘完成。 |

## 6.3 可复用组件

| ID | 组件 | 行为要求 |
|---|---|---|
| CP-01 | 全局导航与顶部状态 | 当前页高亮；待处理跳至内容发布筛选；账户入口提供工作空间/权限。 |
| CP-02 | 结果指标卡 | 显示数值、时间范围、口径、比较对象；无数据时不显示零表现。 |
| CP-03 | 热搜排行行 | 排名、趋势项、地区、变化、热度、聚合状态、查看聚合入口。 |
| CP-04 | 重点主题卡 | 主题是聚合入口；必须通向具体上升话题，不直接创建 Event。 |
| CP-05 | Future Event 芯片/详情 | 确认度、来源、窗口、建议准备与可用操作；不可用操作说明原因。 |
| CP-06 | Event 列表项与 Card | 来源状态、地区、触发原因、版本、任务状态、校正入口和关联关系。 |
| CP-07 | Evidence 行 | 来源名称、链接、地区、快照时间、排序上下文、采集状态和可访问外链。 |
| CP-08 | 账号响应任务行 | 任务 ID、账号、关联 Event、状态、风险、时间和进入详情。 |
| CP-09 | 内容候选卡 | 账号、Skill、版本、预检、来源状态、候选目的、选择/调整/复制操作。 |
| CP-10 | 发布回填表单 | 所选候选摘要、URL 或失败原因、校验结果、提交后持久状态。 |
| CP-11 | 活动方案比较卡 | 三套差异化方案、确认度、假设、资源缺口、选择/调整/导出。 |
| CP-12 | 版本影响预览 | 草稿/生产版本、影响对象、差异、发布/回滚操作。 |
| CP-13 | 对象元数据条 | 来源、最近更新时间、口径/范围、数据状态；详情页用于统一表达新鲜度和数据限制。 |
| CP-14 | 受控导出确认框 | 对象范围、敏感性提示、用途、导出版本与确认操作；完成后显示审计编号。 |

## 6.4 组件状态与使用限制

| 组件 | 默认 | 加载/等待 | 空/受限 | 失败/异常 | 使用限制 |
|---|---|---|---|---|---|
| CP-03 热搜排行行 | 显示排名、趋势、快照与聚合入口 | 保留上次成功快照并标注刷新中 | 筛选无结果说明条件；未启用能力不显示假数据 | 数据源失败显示时间、影响地区与重试入口 | 趋势项不是 Event，必须经聚合入口进入。 |
| CP-05 Future Event 详情 | 显示来源、确认度、窗口与可行动作 | 同步中显示最近成功更新时间 | 无事件可导入或调整筛选；无权限禁用动作并说明 | 来源冲突保留各来源，不显示确定倒计时 | “查看”不得自动创建内容任务或活动方案。 |
| CP-06 Event Card | 显示版本、事实、Evidence、窗口和下游状态 | 聚合中显示当前成功地区及待处理地区 | 未形成 Event 时引导回趋势项；无校正权限显示原因 | 来源不足/冲突显示对象、原因和人工校正入口 | 不出现 Opportunity 或参与决策。 |
| CP-09 内容候选卡 | 同账号 3 条候选可比较和选择 | 生成/预检中保留任务身份与步骤 | 无候选说明账号/Skill 或规则限制 | 显示失败步骤、命中规则、重试/修订入口 | 不同账号候选不得混排；高风险候选不可标为可发布。 |
| CP-10 发布回填表单 | 绑定所选候选并校验 URL | 提交中禁用重复提交、保留草稿 | 无选择候选时不允许回填 | URL 校验/提交失败保留输入并说明原因 | 成功必须显示持久化记录，toast 仅作辅助。 |
| CP-11 活动方案比较卡 | 三个差异化方案并列比较 | 生成中显示 Event 与启动人 | 未主动启动时仅显示建议与限制 | 失败保留启动意图和重试入口 | 导出/交接不等于活动已执行。 |
| CP-13 对象元数据条 | 显示来源、更新时间、口径与状态 | 刷新时保留最近成功值和刷新时间 | 未知口径明确标“待补充” | 来源延迟/失败显示影响范围和诊断入口 | 不得用“最新”代替具体时间。 |
| CP-14 受控导出确认框 | 显示范围、版本、敏感性与用途输入 | 生成导出包时禁止重复提交 | 无权限时说明责任角色和申请路径 | 导出失败保留用途输入与重试入口 | 未填写用途不得导出敏感对象。 |

## 6.5 内容与风险微文案

- 使用“来源一致”“存在冲突”“待确认”，不使用“已证实”替代来源状态。
- 使用“候选已通过规则预检”，不写“系统已发布”。
- 使用“需人工审核”“账号/Skill 不可用”“能力尚未启用”，让用户知道谁或什么阻塞了流程。
- 活动建议使用“建议做准备”“启动生成三套方案”，不写“已立项”“活动执行中”。
- Content Insight 启用后必须标注“引用的可复刻原则”及来源限制，不显示或鼓励复制原文。
