# 07 无障碍与验收

## 7.1 无障碍基线

- Chrome、Safari、Edge 桌面端完成 UJ-1—UJ-5 代表任务无阻塞缺陷。
- 键盘可达率 100%；导航、筛选、列表、候选选择、表单、对话框和外链焦点顺序与视觉顺序一致。
- 图表、热度、来源一致/冲突、风险和预留状态不只依赖颜色；提供文字摘要、时间范围、口径和等价表格/列表。
- 合并/拆分、活动方案和设置修改对话框使用语义对话框：打开后焦点进入标题，Esc 关闭，焦点回到触发按钮。
- 动态生成、预检、回填和失败结果使用适当的 `status` / `alert` 播报；普通刷新不反复打断读屏。

## 7.2 代表任务

| ID | 任务 | 通过标准 |
|---|---|---|
| VT-01 | 在 X 某地区 Top30 中定位已触发趋势项 | 能区分原始趋势项、聚合状态与 Event；两次操作内进入对应 Event。 |
| VT-02 | 在重点主题内查看具体上升话题 | 不把主题当作 Event；可打开具体话题及其聚合状态。 |
| VT-03 | 查看来源冲突 Event | 能找到各地区来源、快照信息和冲突状态；不会把摘要误认为确认事实。 |
| VT-04 | 完成一个普通账号任务 | 在同一账号任务选择、必要时调整、复制一条候选，并回填 URL 或失败原因。 |
| VT-05 | 处理账号/Skill 不可用 | 任务明确为异常；能看见原因和配置修复入口，不会生成替代任务。 |
| VT-06 | 从 Future Event 启动内容预热 | 能说明确认度、窗口、触发来源和创建的账号任务；不重复创建同一 Event 任务。 |
| VT-07 | 启动活动方案 | 运营主动点击后才获得三套方案；能比较确认度、假设、资源缺口并导出。 |
| VT-08 | 键盘完成候选选择和 URL 回填 | 无焦点陷阱；提交结果、校验失败和状态变化可被读屏读出。 |
| VT-09 | 查看结果并提出优化建议 | 能说明样本、观察窗口、口径和数据限制；建议不会直接覆盖生产规则。 |

## 7.5 验收执行记录模板

每一项 VT 和页面状态至少记录：版本或提交、执行日期、浏览器与窗口宽度、执行人、结果（通过/失败）、证据链接、缺陷编号及复测结论。只有所有适用项通过，才可将本章结论更新为“可作为开发验收基线”。

## 7.6 当前验收结论与开放项

本版已经为 v13 原型中的七个运营页面、Event→内容响应链和 Future Event→活动策划支线定义了正式 UX 行为；但上表尚未形成真实浏览器验证记录，故当前结论为 **设计规格待验证**，不能把“有原型示例”当作无障碍、状态或跨浏览器已通过。

以下能力只保留入口或边界，不能以本版验收为已实现：热点内容数据接入与爆款拆解、Content Insight 自动引用方式、活动策划适用 Event 范围、账号表现观察窗口与对照口径。HTML 为完整链路展示；一期只接通本版已确认的 Phase 0 内容响应链。
