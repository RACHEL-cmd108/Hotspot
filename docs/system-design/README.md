# 系统建设方案

本部分定义 Predx 热点运营系统的建设目标、整体架构、热点信源关系、内容生产流程和未来事件中心设想。

## 正式版本

- `releases/Predx热点运营系统建设方案_v2.0.docx`：当前版本。
- `releases/Predx热点运营系统建设方案_v2.0.pdf`：当前版本 PDF。
- `releases/Predx热点运营系统建设方案_v1.0.docx`：历史版本。

## 配图

`assets/` 保存总体架构、热点信源关系和未来事件中心配图。

## 生成方式

在仓库根目录运行：

```bash
python3 build_hotspot_plan.py
```

脚本会更新当前 v2.0 Word 文档及 `assets/` 中的正式配图。
