# 07 非功能需求

产品容量与集成规模由后续架构阶段确认；以下阈值是设计与验收基线，不规定实现方案。

| ID | 类别 | 要求 | 验收方式 |
|---|---|---|---|
| NFR-01 | 工作台可用性 | 工作台必须以文字/图标而非仅颜色呈现待办、窗口、风险、异常、内容样本来源状态和活动建议状态；授权用户可在两次操作内进入相关 Event、账号任务、活动建议，以及**热点内容能力启用后**的热点内容详情。 | 以 UJ-1—UJ-5 代表任务测试，100% 样本满足；热点内容详情仅在该能力启用后纳入样本。 |
| NFR-02 | 性能 | `[ASSUMPTION]` 在确认的首个生产容量下，工作台、Event Card、账号任务与 Future Event 排期的 95% 请求在 3 秒内完成首次可操作呈现；**热点内容详情在能力启用后**纳入同一阈值。 | 使用代表性容量数据集连续测试不少于 20 次，P95 ≤ 3 秒；热点内容详情仅在该能力启用后纳入测试。 |
| NFR-03 | 可靠性与可恢复性 | 单个数据源、结果源或外部交接失败时，已成功数据保留；故障、重试状态和人工接管入口对用户可见。热点内容源失败规则在该能力启用后适用。 | 对每类已启用依赖模拟失败，成功数据丢失数为 0，且每次均可见处置入口。 |
| NFR-04 | 审计完整性 | 事实、证据、内容洞察、规则、账号/Skill、内容候选、审核、任务、活动方案、发布记录与表现结果不得被静默改写或删除。 | 抽样主链、活动策划支线和内容洞察引用链，关键审计字段完整率为 100%。 |
| NFR-05 | 安全、版权与隐私 | 页面、导出、审计和异常信息不得暴露第三方密钥、令牌或密码；热点内容样本展示/引用在该能力启用后必须保留来源和适用限制，敏感字段按角色展示。 | 核心流程、导出和异常样本检查，敏感凭据暴露数为 0；内容洞察启用后抽样其来源字段完整率为 100%。 |
| NFR-06 | 兼容性与可访问性 | 支持当前主流 Chrome、Safari、Edge 桌面端；关键结构、图表与状态可被辅助技术解读。 | 三类浏览器完成 UJ-1—UJ-5 核心任务无阻塞缺陷；键盘可达率 100%。 |
| NFR-07 | 数据时效与口径 | Signal、Event、内容候选、发布记录和表现结果必须展示最近更新时间、来源和口径；热点内容样本在该能力启用后遵循同一要求。不同口径数据不得无提示合并。 | 对每类已启用对象抽样，时间、来源和口径字段完整率为 100%。 |
| NFR-08 | 服务可用性 | `[ASSUMPTION]` 首个生产版本中，热点运营工作台和已创建账号响应任务的月度可用性应不低于 99.5%（计划维护窗口除外）。 | 按月统计可用时长 / 总服务时长，结果 ≥ 99.5%；计划维护须提前记录。 |
| NFR-09 | 故障恢复 | `[ASSUMPTION]` 核心 Event、Content Insight、账号任务、内容候选、活动方案与审计记录发生服务故障后，RTO ≤ 4 小时，RPO ≤ 1 小时。 | 在首个生产容量的恢复演练中，记录并验证 RTO、RPO 分别不超过阈值。 |
| NFR-10 | 隐私最小化与受控导出 | 系统仅收集完成热点运营所需的业务数据；导出含敏感业务数据，或在热点内容能力启用后导出热点内容样本时，必须记录导出者、时间、对象范围和用途。 | 抽样全部敏感导出，审计字段完整率为 100%；不必要数据字段采集数为 0。 |
| NFR-11 | Phase 0 链路可观测性 | 对每个合格热搜 Event，系统必须记录成功采集、各地区前三条来源聚合、任务创建、候选可操作、候选选择、发布链接/失败原因回填的时间与状态；不以固定分钟级时限作为生成或人工处理承诺。 | 覆盖重点领域关键词、普通主题排名 1—5、普通主题排名上升三类触发条件；每个样本的各阶段时间/状态字段完整率为 100%，且正常任务均可追溯至少 3 条候选。 |
