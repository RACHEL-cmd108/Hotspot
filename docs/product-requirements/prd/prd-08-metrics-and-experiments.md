# 08 指标与实验

## 8.1 完整产品成功指标

完整产品指标同时评估流程健康与产品价值。除 Phase 0 已确认指标外，产品级阈值必须在对应团队接入前以基线确认；不能用 Phase 0 内容运营数据替代多团队产品价值。首个多团队试点应连续收集两个周期基线，确认数据来源和责任人后再设定下一周期目标。

| ID | 指标 | 定义 | 目标值/复审条件 | 测量方式 |
|---|---|---|---|---|
| PM-01 | 重要事件覆盖率 | 进入工作流的重要事件 / 复盘认定的重要事件 | `[ASSUMPTION]` 首个多团队试点建立基线后，连续两个周期提升。 | 事件复盘与遗漏登记。 |
| PM-02 | Event 结构化完成率 | 满足最小事实、证据、风险、窗口字段的 Event / 已形成 Event | `[ASSUMPTION]` 试点目标 ≥ 90%。 | Event Card 完整性检查。 |
| PM-03 | 机会判断完成率 | 有四档决策和理由的 Opportunity / 待评估 Opportunity | `[ASSUMPTION]` 试点目标 ≥ 90%。 | Opportunity 状态与决策记录。 |
| PM-04 | 窗口内行动闭环率 | 在有效窗口内完成或正式关闭的 Action Task / 已交接 Action Task | `[ASSUMPTION]` 试点目标 ≥ 85%。 | 事件窗口与 Task Receipt。 |
| PM-05 | 结果可关联率 | 具备至少一项带口径 Outcome 的关闭行动 / 关闭行动 | `[ASSUMPTION]` 试点目标 ≥ 80%。 | 任务、结果和口径检查。 |
| PM-06 | 复盘与经验复用率 | 已完成复盘且建议被批准/采用的行动 / 关闭行动 | `[ASSUMPTION]` 试点目标 ≥ 70% 完成复盘；复用率建立基线。 | 复盘与策略建议记录。 |
| PM-07 | 重要事件发现时长 | 从首个满足监测条件的 Signal 出现，到对应 Candidate Event 进入处理流程的耗时。 | `[ASSUMPTION]` 首个多团队试点建立同类人工流程基线后，连续两个周期缩短。 | 监测日志、Candidate Event 进入时间与人工基线记录。 |
| PM-08 | 有效机会率 | 经行动关闭后的复盘仍被认定为值得参与、且未发生重大事实/风险规则违背的参与机会 / 已参与机会。 | `[ASSUMPTION]` 首个多团队试点建立基线后，连续两个周期提升。 | Opportunity 决策、行动复盘与风险记录。 |
| PM-09 | 跨团队交接时长 | 从 Opportunity Card 作出“优先参与/参与”决策，到责任团队或外部专业系统确认接收 Action Task 的耗时。 | `[ASSUMPTION]` 首个多团队试点建立基线后，连续两个周期缩短。 | 决策记录、Action Task 接收回执。 |
| PM-10 | 目标结果达成率 | 达到 Task Plan 预先选择结果目标的关闭行动 / 具有有效 Outcome 数据的关闭行动。 | `[ASSUMPTION]` 首个多团队试点建立基线后，连续两个周期提升。 | Task Plan 目标、Outcome 与复盘记录。 |

**反向指标：**未经审核的高风险行动数 = 0；无来源事实进入可发布行动数 = 0；无原因的参与覆盖、拒绝、驳回或例外数 = 0；因口径冲突被错误合并的结果数 = 0。

## 8.2 Phase 0 验证实验

| ID | 指标 | 定义 | 目标 | 衡量方式 |
|---|---|---|---:|---|
| P0-01 | 趋势采集完整率 | 实际获得趋势数 / 计划趋势数 | ≥ 95% | 每次采集日志。 |
| P0-02 | 代表性推文覆盖率 | 获得代表性推文的趋势数 / 趋势总数 | ≥ 90% | X 快照。 |
| P0-03 | 事件窗口内完成率 | 在预设有效窗口内完成 Event 形成，并将至少一个可审核草稿投递至已批准 Telegram 审核目标的 Candidate Event 占比 | 首轮建立基线 | Event 形成时间、草稿时间与 Telegram 投递回执时间。 |
| P0-04 | 候选事件处置完成率 | 在规定时间内有明确处置结论的 Candidate Event 占比 | ≥ 90% | 任务状态记录。 |
| P0-05 | 草稿可用率 | 至少一个草稿被人工审核判定为可用的 Candidate Event / 已生成草稿的 Candidate Event | ≥ 60% | Telegram 审核记录与内容运营结论。 |
| P0-06 | 事实/来源质量通过率 | 未出现无来源事实、输入外数字或禁用表达的可审核草稿占比 | 100% | 自动规则检查加人工抽检。 |
| P0-07 | 审核/关闭记录完成率 | 已完成审核或关闭且记录结论的候选事件占比 | ≥ 90% | Telegram 审核记录、任务与复盘记录。 |

**实验边界：**连续验证两周，最少覆盖 30 个进入处理流程的 Candidate Event；当前可行性快照显示 150 个趋势项、144 个代表性推文、8 个候选事件簇和 7 个完整 Event Card，只证明发现、事件形成和草稿投递审核链路可运行，不证明自动发布到社媒账号、完整 Telegram 执行连接器的生产稳定性或产品价值。
