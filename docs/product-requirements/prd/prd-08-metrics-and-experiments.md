# 08 指标与实验

## 7.1 完整产品成功指标

完整产品指标用于评估六层价值。除 Phase 0 已确认指标外，产品级阈值必须在对应团队接入前以基线确认；不能用 Phase 0 内容运营数据替代多团队产品价值。

| ID | 指标 | 定义 | 目标值/复审条件 | 测量方式 |
|---|---|---|---|---|
| PM-01 | 重要事件覆盖率 | 进入工作流的重要事件 / 复盘认定的重要事件 | `[ASSUMPTION]` 首个多团队试点建立基线后，连续两个周期提升。 | 事件复盘与遗漏登记。 |
| PM-02 | Event 结构化完成率 | 满足最小事实、证据、风险、窗口字段的 Event / 已形成 Event | `[ASSUMPTION]` 试点目标 ≥ 90%。 | Event Card 完整性检查。 |
| PM-03 | 机会判断完成率 | 有四档决策和理由的 Opportunity / 待评估 Opportunity | `[ASSUMPTION]` 试点目标 ≥ 90%。 | Opportunity 状态与决策记录。 |
| PM-04 | 窗口内行动闭环率 | 在有效窗口内完成或正式关闭的 Action Package / 已授权 Action Package | `[ASSUMPTION]` 试点目标 ≥ 85%。 | 事件窗口与执行回执。 |
| PM-05 | 结果可关联率 | 具备至少一项带口径 Outcome 的关闭行动 / 关闭行动 | `[ASSUMPTION]` 试点目标 ≥ 80%。 | 任务、结果和口径检查。 |
| PM-06 | 复盘与经验复用率 | 已完成复盘且建议被批准/采用的行动 / 关闭行动 | `[ASSUMPTION]` 试点目标 ≥ 70% 完成复盘；复用率建立基线。 | 复盘与策略建议记录。 |

**反向指标：**未经审核的高风险行动数 = 0；无来源事实进入可发布行动数 = 0；无原因的参与覆盖、拒绝、驳回或例外数 = 0；因口径冲突被错误合并的结果数 = 0。

## 7.2 Phase 0 验证实验

| ID | 指标 | 定义 | 目标 | 衡量方式 |
|---|---|---|---:|---|
| P0-01 | 趋势采集完整率 | 实际获得趋势数 / 计划趋势数 | ≥ 95% | 每次采集日志。 |
| P0-02 | 代表性推文覆盖率 | 获得代表性推文的趋势数 / 趋势总数 | ≥ 90% | X 快照。 |
| P0-03 | 事件窗口内完成率 | 在预设有效窗口内形成可审核草稿的 Candidate Event 占比 | 首轮建立基线 | Event 进入时间、窗口和草稿时间。 |
| P0-04 | 候选事件处置完成率 | 在规定时间内有明确处置结论的 Candidate Event 占比 | ≥ 90% | 任务状态记录。 |
| P0-05 | 草稿可用率 | 至少一个草稿被判为可用的 Candidate Event / 已生成草稿的 Candidate Event | ≥ 60% | 内容运营审核记录。 |
| P0-06 | 事实/来源质量通过率 | 未出现无来源事实、输入外数字或禁用表达的可审核草稿占比 | 100% | 自动检查加人工抽检。 |
| P0-07 | 复盘记录完成率 | 已发布或关闭且完成结果记录的行动占比 | ≥ 90% | 任务与复盘记录。 |

**实验边界：**连续验证两周，最少覆盖 30 个进入处理流程的 Candidate Event；当前可行性快照显示 150 个趋势项、144 个代表性推文、8 个候选事件簇和 7 个完整 Event Card，只证明原型链路可运行，不证明生产稳定性或产品价值。
