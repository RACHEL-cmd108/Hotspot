# 01 产品愿景与目标

## 1.1 产品愿景

Hotspot Monitor 将社会热点、体育赛事、行业事件、市场变化、用户讨论、社区趋势和内部事件转化为共享、可判断、可执行、可衡量、可复用的增长机会。

它不是热榜、内容生成或活动自动化的替代品，而是让热点/研究、内容、产品、渠道、增长、品牌/风控和数据团队围绕同一 Event 完成：`发现 → 事件理解 → 机会决策 → 行动协同 → 结果学习`。

## 1.2 产品目标

1. 更早、更稳定地发现重要事件，并将 Signal、事实、热度和价值区分处理。
2. 为多团队提供同一份持续更新的事件、机会、风险、目标和状态上下文。
3. 将值得参与的事件转化为明确的内容、渠道、产品或关系行动，并在事件窗口内协同。
4. 将判断、行动、成本和结果关联起来，持续优化发现规则、判断策略和行动模板。

## 1.3 成功定义

当重要事件出现时，相关团队不再依赖临时消息、分散表格和重复查询拼接背景；能在 Hotspot Monitor 内达成事件共识、作出机会决策、完成任务交接、取得结果回执并复用经验。

## 1.4 当前验证目标

Phase 0 在 Predx 内容运营的突发热点快速响应场景验证最短内容闭环：从一次成功的小时级热搜采集首次记录到合格触发起，系统须在 5 分钟内生成至少 3 条通过规则预检的普通社媒内容候选，并由 Telegram Bot 投递至管理员批准的审核目标。内容运营在投递后 15 分钟内选择其中一条、人工发布，并回填实际发布链接；Bot 不直接发送到任何社媒特定账号。高风险内容不得默认通过，须经品牌/风控人工审核后才可发布。该验证不改变完整产品的多团队和 M1–M5 范围。
