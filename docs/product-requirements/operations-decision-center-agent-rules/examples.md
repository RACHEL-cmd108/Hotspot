# 校准与验收样例

以下为规则样例，不代表真实市场、真实概率或产品承诺。测试数据必须显式标记 fixture。

## 例1：公共关注度 + 直接市场承接

输入：官方确认下周举行发布会；目标热搜 Top 3；存在开放市场“是否在指定日期前发布某产品”，结算时间与主体一致。

预期：

- `public_attention = met`，X 短时增速榜前 3；
- 市场匹配 `direct`；
- `recommended / market / immediate`；
- Angle 可覆盖新证据影响、时间节点、条件路径；
- 具体概率只有在新鲜快照存在时显示。

## 例2：无市场 + 自然产品价值承接

输入：一个高质量内容结构正在扩散；无对应开放市场；该结构适合解释“新证据如何改变判断”，且命中已上线事件研究能力。

预期：

- 市场匹配 `none`；
- 产品价值匹配成立；
- `recommended / product_value / today`；
- Angle 指向信息更新、已知未知或研究路径；
- 不虚构市场、概率或实时市场入口。

## 例3：公共关注度 + 暂无承接

输入：娱乐事件跨地区 Top 1；当前无真实市场；Agent 找不到具体产品价值连接。

预期：

- X 短时增速榜前 3，Agent 输出 `public_attention = met`；
- `recommended / attention_only / immediate`，立即响应依据为 URG-01；
- `angle_set.status = no_mature_angle`；
- 输出待人工探索及缺失承接方式；
- 不生成品牌露出或“任何事都可预测”角度。

## 例4：只有“网上很火”的描述

输入：人工写“这件事现在全网都很火”，没有平台、观测时间、数值、策略结论或证据引用。

预期：

- `public_attention = uncertain`；
- 缺少 X 短时增速排名和快照；
- 若市场和产品价值均不成立，则 `context_required`；
- Agent请求热度观测或人工强制准入，不自行判断为热门。

## 例5：关键事实触发立即响应，但公共关注度一般

输入：PredX 相关监管机构刚发布正式决定；公共关注度未达到阈值；事件直接影响产品用户和行业规则。

预期：

- `public_attention = not_met`；
- `product_value_match = met`；
- `handling = immediate`，命中 URG-03；
- 说明立即响应不依赖公共热度。

## 例6：主题相似但结算冲突

输入：事件与市场标题均包含同一公司，但事件发生时间晚于市场规则截止时间。

预期：

- 市场匹配 `none` 或 `possible`，不得为 `direct`；
- 记录结算时间冲突；
- 若无其他准入路径则不推荐或人工复核。

## 例7：候选角度实质重复

候选：

1. 新消息如何改变市场概率？
2. 市场为何因新消息重新定价？
3. 最新信息对概率有什么影响？

预期：三者属于同一“新证据影响”主张，只保留依据和表达最清楚的一条，再探索其他承接面。

## 例8：重新推荐

用户保留 MA-03，拒绝 MA-01 和 MA-02，原因“角度重复，希望考虑结算条件和相关市场”。

预期：

- 保留 MA-03；
- 不返回 MA-01/MA-02 的改写；
- 优先探索 MA-08 和 MA-09；
- 新 Angle Set 保存版本、反馈与差异摘要；
- 默认只影响当前事件。

## 例9：偏好反馈与质量纠错分流

- “我不喜欢这个受众” → 偏好反馈；
- “这个市场在事件发生前已经结算” → 质量纠错；
- “这个角度太像标题” → 偏好/结构反馈；
- “引用的概率没有时间戳” → 质量纠错。

质量纠错进入复核，不自动改写事实、市场规则或全局策略。
