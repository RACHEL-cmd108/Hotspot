# 规则包自查记录

日期：2026-08-28  
结论：规则骨架已闭环，可进入产品确认；三个配置项与真实校准集补齐前，不应直接作为生产规则发布。

## 1. 自查范围与结果

|---|---|---|

## 2. 已发现并修正的问题

1. 公共关注度改为程序资格结论加 Agent 解释，Agent 不再凭语感判断热度。
2. 响应节奏独立为 `immediate / today`；仅 X 短时增速榜前 3、未来 12 小时内关键节点、过去 2 小时内直接相关的关键事实可触发立即响应。
3. 原输出合同没有完整记录重新推荐的触发动作和候选变化；现已加入 `generation` 版本差异字段。
4. 市场和公共关注度阈值均由版本化策略负责，Agent 不自行猜阈值。

## 3. 发布前仍需外部补齐

这些内容不应由 Agent 自行创造：

1. `public_attention_policy_version`：目标公众范围、各来源阈值、组合条件、去同源和缺数降级。
2. `market_freshness_policy_version`：不同字段和市场状态的数据过期阈值。
3. 当前运营目标与目标用户配置：用于筛选和排序角度，不写死在通用规则中。
4. 校准样例集：建议至少 20 个真实事件、10 组市场匹配正反例、10 组产品承接正反例、5 组重新推荐前后例。

## 4. 基线冲突提醒

本规则包采用“可接收任意来源上下文、独立完成判断”的新边界；2026-08-24 旧 PRD 采用更强的上游对象依赖。开发前必须明确以哪一版为实现基线，不能把两套输入边界静默混用。
